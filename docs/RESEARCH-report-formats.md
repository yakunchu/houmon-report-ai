# 報告書の出力形式の調査と仕様案（医師・ケアマネ・介護職 × FAX・メール・チャット）

- 作成日: 2026-11-05（2026年11月時点の情報）
- 位置づけ: 調査メモと仕様案。実装の正本は `CLAUDE.md` と `docs/PLAN.md`。本書の「提案」はまだ決定ではない。
- 根拠: 4 テーマ（医師宛て・ケアマネ宛て・介護職への共有・送付手段と個人情報）の調査結果。どれも別の担当が原文と照らして査読済み。本書を書く段階では原文を取り直していない。製品の画面や文書に引用するときは、原文をもう一度確認すること。
- 表記: 【事実】は出典がある内容。【提案】は本書が出す設計案（出典はない）。「（参考）」は業者・ブログだけが根拠の事項。

---

## 0. アプリの現状（2026-11-05 時点）

- 会話（文字起こし）から「居宅療養管理指導報告書」の各欄を下書きする。欄は選択式 13 欄（服薬状況〜日常でみられる傾向。残薬は自由入力、食事・回数は数値）と、それぞれの備考、SOAP。会話に根拠がない欄は「要確認」になる（`CLAUDE.md`「報告書の欄」）。
- 宛先は 医療機関／ケアマネ／その他 の 3 つ。医師向けとケアマネ向けは同じ書式で、宛先だけを切り替える（`CLAUDE.md`）。
- ④出力は 1 種類のプレーンテキスト。並びは 宛名 → 基本情報 → 処方内容 → 会話から記入する欄 → SOAP（【指導内容】）→ 定型欄（指導相手・後発品希望・お薬手帳）。端末内で名前を戻してから、コピー・印刷する（`src/lib/report/format.ts`）。

## 1. 制度上の根拠（要点）

### 1-1. 医師への報告（医療保険・介護保険）

- 【事実】2026年11月時点の調剤報酬の留意事項通知は、令和8年度改定版（令和8年3月5日 保医発0305第6号 別添3）。令和6年度（2024年度）版（保医発0305第4号）の別添3の本文は今回読めていない。両者の文言が同じかどうかは未確認。
  出典: https://kouseikyoku.mhlw.go.jp/kinki/shinsei/shido_kansa/zaitaku/index.html
- 【事実】在宅患者訪問薬剤管理指導料は、指示を行った医師に「訪問結果について必要な情報提供を文書で行った場合」に算定する（区分15 1(1)、令和8年版）。算定は月4回まで。末期の悪性腫瘍、注射による麻薬投与、中心静脈栄養法の患者は週2回かつ月8回まで。
  出典: https://kouseikyoku.mhlw.go.jp/kinki/000498182.pdf
- 【事実】薬剤服用歴等には、訪問の実施日と薬剤師名、処方医から受けた情報の要点、実施した薬学的管理指導の内容、「処方医に対して提供した訪問結果に関する情報の要点」、他職種と共有した内容の要点を記載する（区分15 1(10)）。薬学的管理指導の内容の例は、保管状況、服薬状況、残薬、併用薬、併診、体調の変化（副作用が疑われる症状など）、重複服用、相互作用、実施した服薬支援措置。
  出典: 同上
- 【事実】連携する他の医師の求めで訪問した場合は、在宅療養を担う医療機関の医師にも文書で情報提供する。麻薬管理指導加算では、処方医への情報提供（鎮痛効果や体調変化など）が要件になる（区分15 1(1)、区分15の2）。
  出典: 同上
- 【事実】在宅患者訪問薬剤管理指導料を算定した月は、服薬情報等提供料（トレーシングレポート）を算定できない（区分15 1(11)）。訪問報告書とトレーシングレポートは別の枠組みである。
  出典: 同上
- 【事実】報告の頻度（毎訪問か月1回か）を単独で定めた文言は、医療保険でも介護保険でも見つからなかった。文書による報告は算定要件の一部として書かれている。「少なくとも1月に1回」は薬学的管理指導計画の見直しの頻度で、報告の頻度ではない。
  出典: 同上
- 【事実】介護保険の居宅療養管理指導（薬局薬剤師）では、医師・歯科医師に報告したうえで、ケアマネジャーにケアプラン作成等に必要な情報を提供する。根拠は告示第19号 別表5ハ注1、老企第36号 第2の6(4)①（東京都の令和7年度集団指導資料による。老企第36号の令和6年度改定後の原文そのものは未読）。指示医への文書の写しは、記録に添付するなどして保存する。
  出典: https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/r7shuudanshidou-kyotakuyakkyoku-pdf ／ https://www.city.kurume.fukuoka.jp/1500soshiki/9045kaigo/3010oshirase/files/yakuzaisii.pdf
- 【事実】医師は、薬剤師からの報告による留意事項を診療録に記載し、薬剤師の文書は診療録に添付するなどして保存する。報告書は医師側で「カルテに綴じる紙」になる前提で作る。
  出典: 東京都資料（上記）

### 1-2. ケアマネジャーへの情報提供（介護保険）

- 【事実】老企第36号の薬剤師の項に「ケアマネジャーへの情報提供がない場合には、算定できない」とある（令和3年度改定時の新旧対照表で原文を確認）。
  出典: https://www.mhlw.go.jp/content/12301000/000750738.pdf
- 【事実】平成30年度（2018年度）介護報酬改定 Q&A（Vol.3、平成30年4月13日）に、ケアマネへの情報提供が「必ず必要になった」という問いがある。答えは、月に複数回算定する場合も「毎回行うことが必要」。状態に変化がなければ、変化がないことを伝える、または利用者・家族への指導・助言の内容を伝えればよい。ただしこの例示は往診時の指導を挙げており、医師を念頭に置いた書き方である。「2018年度に必須化」はこの Q&A の文言からの間接的な確認にとどまる。
  出典: https://www.mhlw.go.jp/content/12404000/001622724.pdf
- 【事実】1か月に複数回算定する場合も、1か月分をまとめて情報提供することはできない（福岡県等の令和5年度集団指導資料）。
  出典: https://www.city.kurume.fukuoka.jp/1500soshiki/9045kaigo/3010oshirase/files/yakuzaisii.pdf
- 【事実】令和6年度（2024年度）改定で、「医師・ケアマネジャー等への情報提供は、多職種連携推進のための在宅患者訪問薬剤管理指導ガイド及びガイド別添の報告様式、お薬問診票及び薬学的評価シートを参考に行う」旨が追加された（東京都資料の「令和６年度追加」）。改定の通知本体（介護保険最新情報 Vol.1213、令和6年3月15日）は、ファイルが大きく取得できなかった。
  出典: 東京都資料（上記）
- 【事実】兵庫県の手引き（令和6年6月）が引用する老企第36号には、次の 2 点が書かれている。(1) ケアマネへの情報提供は「利用者の同意を得て行うものに限る」。(2) 服薬状況や保管状況に問題があり、訪問介護員等の援助が必要な場合は、関連事業者等に情報提供と助言を行う。県による引用で、厚労省の原文ではない。
  出典: https://web.pref.hyogo.lg.jp/kf27/documents/kyotakuryouyoukanrisidou.pdf
- 【事実】情報提供の方法（サービス担当者会議を基本とし、出られないときは文書。メールや FAX でもよい）は、老企第36号の医師・歯科医師の項に書かれている。薬剤師の項に同じ文言があるかは、読んだ範囲では確認できなかった。
  出典: https://www.mhlw.go.jp/content/12301000/000750738.pdf

### 1-4. 参考にする様式

- 【事実】国の必須様式はない。令和6年度以降の参考様式は、国立長寿医療研究センターの研究班による「多職種連携推進のための在宅患者訪問薬剤管理指導ガイド」（第1版。作製日 2024年1月、公開は同年3月頃）の別添3「訪問薬剤管理指導の報告書」。ガイドは、報告書を「主訴」と「服薬管理・機能評価に対する薬学的アセスメント」を中心に組み、医師・多職種への情報提供と処方提案は「わかりやすく別立てとした」と説明している。
  出典: https://www.ncgg.go.jp/hospital/kenshu/organization/documents/20240308_zaitakuhoumonyakuzai_guide.pdf ／ 様式 https://www.ncgg.go.jp/hospital/kenshu/organization/documents/20240208_houkokusyo.pdf
- 【事実】別添3 の欄: 報告日、訪問日、医療機関名、処方医、ケアマネジャー、患者氏名・性別・生年月日・連絡先、薬局名・住所・電話・薬剤師名、訪問目的、患者及び介護者の主訴、服薬管理状況まとめ、薬物有害事象（なし／あり）、残薬の有無・残薬調整・頓用薬調整の要否、薬学的評価シートのアセスメントのまとめ、医師・他職種への連絡事項（処方提案等）、次回訪問予定日、次回への申し送り。欄の配置（紙面の位置）は目で確かめていない。
  出典: 同上
- 【事実】医師とケアマネ共通の 1 枚様式で、宛先をチェックで選ぶ例もある（鹿児島県薬剤師会、平成24年度版。古い資料）。
  出典: https://kenyaku.sakura.ne.jp/wordpress/wp-content/uploads/2013/05/ebdb1cdac2a1ebc2df3f1fdfa9ecb5b7.pdf

**現行アプリとの差（【提案】の材料）**: 別添3 にあって今の出力にないのは、「訪問目的」「主訴」の見出し（S が近い）、「薬物有害事象 なし／あり」、「医師・他職種への連絡事項（処方提案等）」を別立てにした欄、「次回への申し送り」。今の出力では、処方提案もケアマネへのお願いも P の中に混ざっている。

## 2. 宛先別の項目

### 2-1. 医師（処方医）

| 区分 | 項目 | 根拠 |
|---|---|---|
| 必ず入れる | 訪問日、報告日、薬剤師名、薬局の連絡先 | 区分15 1(10) ア（薬歴の記載事項）。別添3 の欄 |
| 必ず入れる | 訪問結果（服薬状況、保管状況、残薬、併用薬・併診、体調の変化＝副作用が疑われる症状、重複・相互作用、実施した服薬支援） | 区分15 1(1)(10)、令和8年版 |
| 必ず入れる | 処方医への連絡事項・処方提案（別立て。例: 残薬による日数調整） | ガイド別添3「わかりやすく別立て」 |
| 必ず入れる（該当時） | 麻薬の鎮痛効果・体調変化 | 区分15の2 |
| あると良い | 薬物有害事象 なし／あり の明示 | 別添3 の欄 |
| あると良い | 生活状況（食事・嚥下・排泄・睡眠・運動・移動） | 別添2「薬学的評価シート」の項目 https://www.ncgg.go.jp/hospital/kenshu/organization/documents/20240208_hyoukasheet.pdf |
| あると良い | 次回訪問予定日、次回への申し送り | 別添3 の欄 |
| あると良い | 分包や残薬調整をした場合はその理由 | 旭中央病院薬剤局のトレーシングレポート運用資料（病院の資料。在宅報告書専用ではない） https://www.hospital.asahi.chiba.jp/common/pdf/section/medicine/tracingreport_operations.pdf |
| 入れない方がよい | 主観的な情報だけで終わる記載（観察した事実と提案を添える） | 同上 |
| 入れない方がよい | 必要な範囲を超える情報 | 個人情報ガイダンス「本来必要とされる情報の範囲に限って提供すべき」 https://www.mhlw.go.jp/content/001470633.pdf |
| 入れない方がよい（【提案】） | ケアマネへのお願い（ヘルパーの声かけなど）を、医師宛ての本文の主文にすること。医師宛てでは「多職種と共有済み」の 1 行にとどめる | 公的な根拠はない。宛先ごとの役割の違いからの編集上の判断 |

- 【事実】医師が報告書に何を求めるかを医師に聞いた調査は見つからなかった。病院薬剤部の資料には「時系列で簡潔にわかりやすく記載してください」とある（旭中央病院、2022年3月1日）。

### 2-2. ケアマネジャー

| 区分 | 項目 | 根拠 |
|---|---|---|
| 必ず入れる | ケアプラン作成等に必要な情報（服薬状況、保管・管理の状況、生活への影響） | 告示・老企第36号（東京都資料、厚労省 R2.10.22 資料 https://www.mhlw.go.jp/content/12300000/000685776.pdf ） |
| 必ず入れる | 算定のたびの提供。変化がなくても「変化なし」と、指導・助言の内容 | 平成30年度 Q&A（Vol.3） |
| 必ず入れる（該当時） | 訪問介護員等の援助が必要な点（例: 服薬の声かけ、カレンダーへのセット） | 兵庫県手引き（老企第36号の引用） |
| 必ず入れる（該当時） | 薬の追加・中止・増減・用法や剤形の変更 | ガイド。用法が朝食後から夕食後に変わったのに共有されず、重ねて飲ませてしまう例を挙げている |
| あると良い | 生活面（食事・嚥下・排泄・睡眠・移動・転倒・服薬介助の必要度） | 別添2 薬学的評価シート |
| あると良い | 残薬の数だけでなく原因（用法が生活に合わない等） | ガイド |
| あると良い | 医師に提案したこと（結果待ちであること） | 別添3「医師・他職種への連絡事項」 |
| 入れない方がよい（【提案】） | 専門用語や薬理の説明のまま書くこと（平易に言い換える） | 服薬情報等提供料2のハは、ケアマネが「理解しやすい表現」で提供するとしている（医療保険の別の枠組み。居宅療養管理指導の要件ではない） https://www.mhlw.go.jp/content/001713154.pdf |
| 入れない方がよい | 必要な範囲を超える情報（ケアプランに関係しない検査値の詳細など） | 個人情報ガイダンス |

- 【事実】ケアマネ調査（令和元年度老健事業、n=957）では、服薬の情報を共有した効果として「利用者の服薬の状況が改善された」が 65.4% で最も多かった。ケアマネから薬剤師に伝える情報の例は、薬が大量に余っている、複数回分を一度に飲んでいる、服薬を拒否している、食事量・回数の変化、下痢・便秘が続く、など。
  出典: https://www.mhlw.go.jp/content/12300000/000685776.pdf
- 【事実】厚労科研の多職種アンケートでは、薬剤師が伝えている情報は残薬や管理が中心だった。多職種は、有効性・安全性（処方の見直し等）の情報を求めていた。
  出典: https://mhlw-grants.niph.go.jp/system/files/report_pdf/202315005A-buntan8.pdf

### 2-3. 介護職（ヘルパー・施設の介護職員）

制度上、介護職は報告書の算定要件の宛先ではない（宛先は医師とケアマネ）。介護職への共有は、ケアマネ経由、または「関連事業者等への情報提供・助言」（兵庫県手引き）として行う。

| 区分 | 項目 | 根拠 |
|---|---|---|
| 必ず入れる | 何を・いつ・どう飲む／使うか（用法）と、今回変わった点 | ガイド（用法変更の共有） |
| 必ず入れる | 介護職にお願いする介助の範囲（例: 一包化された薬の内服介助、お薬カレンダーへのセット、服薬直前の PTP からの取り出し、湿布の貼付、点眼、坐薬、吸入） | 医政発第0726005号（2005年） https://www.mhlw.go.jp/web/t_doc?dataId=00tb2895&dataType=1&pageNo=1 、その2（2022年） https://www.mhlw.go.jp/content/001486239.pdf 、その3（2025年12月26日） https://www.mhlw.go.jp/content/001624372.pdf |
| 必ず入れる | 観察してほしいことと、報告してほしいこと（例: むせの増加、ふらつき、食欲低下、便秘） | 「原則として医行為ではない行為に関するガイドライン」（2025年3月）。ガイドラインは「医療職より予め指示のあった事項について報告」するとしている https://www.mhlw.go.jp/content/001728796.pdf |
| 必ず入れる | 連絡先。急変・緊急時は電話 | 岡山市・福島市の MCS 運用ルール、厚労省 ICT 事例集（下記 3(c)） |
| あると良い | 飲み合わせの注意など、生活での具体的な注意 | 同ガイドライン（ワーファリンと納豆等の例） |
| 入れない方がよい | 病名・検査値など、介助に要らない情報 | 個人情報ガイダンス（必要な範囲に限る） |
| 入れない方がよい | 抗血栓薬など専門的な管理が要る薬の判断を、介護職に任せる書き方 | その3 通知の注2（免許を持つ者が判断し、用法の遵守と内容を確認する） |
| 入れない方がよい（【提案】） | 飲み忘れたときの一般的な対応 | 公的な標準手順は見つからなかった。「薬ごとに薬剤師・医師に確認」と書くにとどめる |

- 【事実】その3（2025年）で、サービス担当者会議等で確認する相手に薬剤師が加わった（2022年の通知は医師・歯科医師・看護職員）。PTP シートはハサミで 1 錠ずつに切り離さないよう留意する、とある。

## 3. 送付手段別の体裁と注意

### (a) FAX・印刷

- 【事実】報告書を A4 1 枚に収めるという決まりは見つからなかった。公的様式（別紙様式1-1）は、必要なら続紙を添付するとしている。
  出典: https://www.mhlw.go.jp/content/12404000/000907843.pdf
- 【事実】厚労省の様式例（別紙様式1-1）には「保険薬剤師氏名 印」の欄がある。令和2年12月25日の整理省令で省令様式の押印欄は削除されたが、薬局・介護向けに押印を一律に不要とする通知は見つからなかった。押印の要否は、送り先の様式と運用で決まる。
  出典: https://www.mhlw.go.jp/stf/newpage_15544.html
- 【事実】FAX 送付状の記載事項を定めた国内の公的資料は見つからなかった。誤送信の防止策として確認できたのは次の 4 つ。
  - 介護事業所向けの手引き（令和8年4月）のチェック項目「メールや FAXの宛先の確認を徹底し、送信ミスを防止している」 https://www.mhlw.go.jp/content/12306000/001719620.pdf
  - 病院の公表事例。電子カルテに登録したかかりつけ医の情報が古いまま、旧かかりつけ医に誤送信した。再発防止策は、登録情報の更新と、患者への確認（大阪府の病院、令和6年11月） https://gh.opho.jp/pdf/leukage20241111.pdf
  - 病院の公表事例。FAX 番号を誤って送信し、送信後に電話で受信を確かめたことで判明した（東京大学医科学研究所附属病院、平成27年6月） https://www.u-tokyo.ac.jp/content/400032537.pdf
  - 個人情報保護委員会の Q&A Q3-9。薬局が疑義照会の FAX を誤送信したら、まず送信先に連絡し「当該情報を廃棄してもらう」 https://www.ppc.go.jp/personalinfo/faq/iryoukaigo_guidance_QA/
- 【事実】大阪大学医学部附属病院薬剤部は、FAX の誤送信を理由に、2026年7月13日から緊急でない FAX の送信を最小限にした（疑義照会票の FAX 返信は継続）。トレーシングレポートの受付方法は病院ごとに違う（FAX、PDF のメール添付、郵送、Web フォーム）。
  出典: https://www.med.osaka-u.ac.jp/pub/hp-drug/pharm/cms/media/notice_pharmacies.pdf ／ https://www.toyaku.or.jp/improvement/progress/pdf/iryoukikann_R5_3.pdf
- 【事実】誤送信で要配慮個人情報が漏えいした場合は、個人情報保護委員会への報告と本人への通知が必要になりうる（ガイダンスⅣ8）。報告の期限は今回確認していない。
  出典: https://www.ppc.go.jp/files/pdf/260401_iryoukaigo_guidance.pdf

**【提案】A4 1 枚の構成（上から）**

1. 宛名（医師:「〇〇クリニック 内科 〇〇 先生御侍史」／ケアマネ:「〇〇居宅介護支援事業所 ケアマネジャー 〇〇 様」）と、右肩に報告日
2. 表題「居宅療養管理指導報告書」と、発信元（薬局名・住所・TEL・FAX・薬剤師名）
3. 患者（氏名・カナ・生年月日・年齢・性別）、訪問日、次回訪問予定日
4. **連絡事項（別立ての枠。1〜3 行）** … 医師宛ては処方提案、ケアマネ宛てはお願い
5. 服薬管理（訪問頻度・調剤形態・服薬管理者・管理方法・服薬状況・残薬）を 2 列の表に
6. 生活状況（食事 3 欄・排泄 2 欄・睡眠 2 欄・運動・移動・日常でみられる傾向）を 2 列の表に
7. 指導内容（S・O・A・P）
8. 定型欄（指導相手・後発品希望・お薬手帳）
9. 処方内容。1 枚に収まらなければ「別紙（処方内容）」として 2 枚目に回す

- 目安: 本文 10.5〜11pt、余白 15mm（FAX の読み取りで端が欠けないように）。表は罫線、色に頼らない（FAX は白黒）。
- 「御侍史」「御机下」の使い分けは公的な規定が見つからなかった（参考: 求人系サイトの解説 https://job-medley.com/tips/?p=40743 ）。病院の様式でも「先生御侍史」（名古屋市立大学附属東部医療センター）と「担当医 科 殿」（厚労省様式）が混在している。ケアマネ宛ての敬称「様」の公的な根拠も見つからなかった。

**【提案】FAX 送付状（1 枚目に付けるか、報告書の上部に印字する）**

- 宛先: 施設名、担当者名、**FAX 番号（大きく）**
- 送信元: 薬局名、担当薬剤師名、TEL、FAX
- 送信日時、枚数（送付状を含む）、件名（「居宅療養管理指導報告書（11/5 訪問分）」）
- 患者名は送付状に書かず、報告書の本文に書く
- 誤って届いた場合の依頼文（例:「誤って届いた場合は、お手数ですが破棄のうえ上記 TEL までご連絡ください」）

**【提案】誤送信の防止（アプリでできること）**

- 患者リストの宛名に FAX 番号を持たせ、送付状に印字する（手入力をなくす）
- 印刷の前に「宛先と FAX 番号を確認しました」のチェックを求める
- 宛名・番号の最終更新日を表示する（古い登録情報が誤送信の原因になった事例への対策）

### (b) メール

- 【事実】医療情報システムの安全管理に関するガイドライン第7.0版（概説編・経営管理編・システム運用編は令和8年6月、Q&A は令和8年9月）の 13 章は、電子メールを「オープンなネットワーク」に分類する。外部に医療情報を送るときは、必要に応じて送信する情報自体を暗号化する（13.3.2）。メールで送る場合、医療機関等が使うメールサーバまでは医療機関等が責任を持つ（3.5 責任分界）。
  出典: https://www.mhlw.go.jp/content/10808000/001716295.pdf ／ 一式 https://www.mhlw.go.jp/stf/shingi/0000516275_00006.html
- 【事実】パスワード付き PDF の是非と、「メール本文に患者氏名を書かない」運用について、第7.0版の各編と Q&A には記載が見つからなかった。介護事業所向けの手引き（令和8年4月）に、チェック項目「重要情報はパスワード保護した添付ファイルに記載している」がある（法令ではない）。パスワードを別送するかどうかは未確認。
  出典: https://www.mhlw.go.jp/content/12306000/001719620.pdf
- 【事実】受け手の指定がある場合はそれに従う。例: 指定のアドレスに PDF を添付し、件名に薬局名と「トレーシングレポート」と書くよう求める病院がある（東京都薬剤師会の一覧）。
  出典: https://www.toyaku.or.jp/improvement/progress/pdf/iryoukikann_R5_3.pdf
- 【事実】連携先への情報提供は、利用目的として公表していれば原則として黙示の同意があると考えられる。ただし傷病の内容によっては明確な同意が求められる。メール送付に限った同意の要否は、公的資料で確認できなかった。
  出典: https://www.ppc.go.jp/files/pdf/260401_iryoukaigo_guidance.pdf

**【提案】メールの型**

- 件名: `【居宅療養管理指導報告】11/5訪問分（ジロー薬局）` … 患者名を入れない
- 本文: 宛名 → 1 行の要旨（患者名を入れない）→ 添付のご案内 → 署名
- 報告書の本体は PDF で添付する。パスワード付き PDF を作る機能は今のアプリにない。作るなら、方式（ブラウザ内で暗号化できるか）とパスワードの渡し方を別に確かめてから決める。
- 本文に氏名を書かない運用は公的な根拠が見つからなかった。誤送信したときの被害を小さくするための、アプリの既定とする提案にとどめる。

### (c) チャット・多職種 SNS（MCS など）

- 【事実】第7.0版 Q&A（Q10）は、「SNS 等の Web サービスは利用可能ですが」、医療情報システムとして安全性を評価する必要があり、「一般向けSNS を安易に利用せず」としている。HISPRO の資料を参考に挙げる。HISPRO の資料は、公開型の SNS（LINE 等）は機微な情報の連携に向かず、非公開型が望ましいとする（2016年の資料。版の日付には不確かさがある）。
  出典: https://www.mhlw.go.jp/content/10808000/001752355.pdf ／ https://hispro.or.jp/open/pdf/SNS_RiyouCheckJikou_20160126.pdf
- 【事実】地域の運用ルールでは、次のことが決まっている。
  - 緊急連絡は原則として電話で行い、MCS は 24 時間の拘束をしない（岡山市・岡山市医師会）
  - グループは利用者ごとに作り、書き込みは「その利用者に関することのみ」。利用は原則 7〜20 時。スクリーンショットは禁止（福島市医師会、2025年6月）
  - 急変時は電話・FAX を併用する（泉州南圏域、2019年）
  - 薬局の事例でも、緊急対応は MCS でなく電話（厚労省 ICT 事例集、令和8年3月）

  出典: https://www.city.okayama.jp/kurashi/cmsfiles/contents/0000041/41594/MCS_unyouhousin.pdf ／ https://www.f-renkei.net/wp-content/uploads/2025/06/f8e7a98adbbf65925bbe62a62fb22ec4.pdf ／ https://www.sano.osaka.med.or.jp/ICT_guidelines.pdf ／ https://www.mhlw.go.jp/content/10802000/001683299.pdf
- 【事実】チャット報告の短文の型を定めた日本の公的資料・職能団体の資料は見つからなかった。患者氏名の書き方（フルネーム／イニシャル）を定めた国の指針も、岡山市・福島市の規程にもなかった。

**【提案】短文の型（200 字以内）**

- 1 行目: 要点（何が起きて、何をしたか）
- 2〜3 行目: 事実（残薬・体調など。1 行 1 事実）
- 4 行目: お願い／ご検討（宛先に応じて変える）
- 末尾: 薬局名・薬剤師名
- 氏名は書かない。利用者ごとのグループに書き込む運用（福島市）なら、氏名がなくても誰の話か分かる。グループの外（個人宛てメッセージ等）に送るときは、地域のルールに従う。
- 緊急・急変の内容はチャットに書かず電話する、と出力画面に表示する。

## 4. アプリへの提案: ④出力を 3 形式にする

### 4-0. 共通方針

- 形式は 3 つ: 「印刷・FAX 用（A4）」「メール用」「チャット用」。宛先（医師／ケアマネ／介護職）は、どの形式でも差し込む部分だけを変える。
- 元のデータは今と同じ（確定した下書き＋患者リストの基本情報）。どの形式も確定後に端末内で作る。サーバーや AI には送らない（今の方針のまま）。
- 「連絡事項（1〜3 行）」と「要点（1 行）」は今の下書きにない。作り方は 2 案ある。A: 下書きのスキーマに欄を足し、AI が P から抜き出して薬剤師が直す。B: 薬剤師が手で書く。A はスキーマ・評価の変更が要り、B は入力の手間が増える。

### 4-1. 印刷・FAX 用（A4）

順番: 送付状（任意）→ 宛名・報告日 → 表題・発信元 → 患者・訪問日・次回 → **連絡事項** → 服薬管理の表 → 生活状況の表 → SOAP → 定型欄 →（別紙）処方内容
含める欄: 全欄。省く欄: なし（処方内容は 2 枚目に回してよい）
文字数の目安: 本文 800〜1,200 字（A4 1 枚。10.5〜11pt の場合）

架空の例（ケアマネ宛て。架空患者 山本花子さん、`fixtures/yamamoto-hanako/`）:

```
あおぞら居宅介護支援事業所　ケアマネジャー 佐藤 美和 様        2026年11月5日

                   居宅療養管理指導報告書
              ジロー薬局　薬剤師 前田 二郎（TEL ／ FAX）

患者：山本 花子（ヤマモト ハナコ）1940年4月1日 86歳 女性
訪問日：2026年11月5日　次回訪問予定日：2026年12月3日（28日毎）

┌ 連絡事項 ───────────────────────────
│ ・朝の飲み忘れが週3回程度。服薬カレンダーを食卓の見える位置に設置しました。
│ ・ヘルパー訪問時に、服薬確認の声かけをご検討ください。
│ ・残薬4日分は、次回処方での日数調整を医師に提案します。
└──────────────────────────────────

【服薬管理】                    【生活状況】
調剤形態　一包化（別包有）       食事　量 普通／3回/日／嚥下 問題なくできる（むせなし）
服薬管理者 本人（長女が週末確認） 排泄　尿 普通（夜間2回）／便 便秘（3日に1回）

【指導内容】S「朝はバタバタして、薬を飲んだか分からんようになる」…
            O … A … P …
【定型欄】指導相手 本人／後発品希望 確認済み／お薬手帳 シール貼付
（別紙：処方内容）
```

**宛先で変わる部分**

| 部分 | 医師 | ケアマネ | 介護職 |
|---|---|---|---|
| 宛名 | 〇〇 先生御侍史 | ケアマネジャー 〇〇 様 | 〇〇事業所 ご担当者 様 |
| 連絡事項 | 処方提案（例: 残薬4日分のため次回の日数調整をご検討ください） | お願い（ヘルパーの声かけ）と、医師に提案した事実 | 介助の範囲と観察してほしい点 |
| 処方内容 | 本文に入れる | 別紙でよい | 用法の一覧だけ（「朝食後の袋」など平易に） |
| SOAP | そのまま | A を平易に言い換えてもよい | 載せない。「お願い」「観察」の箇条書きに置き換える |

### 4-2. メール用

順番: 件名 → 宛名 → 要旨 2〜3 行（氏名なし）→ 添付のご案内 → 署名
含める欄: 連絡事項。省く欄: 氏名・生年月日・住所・処方内容・選択式の欄（添付 PDF に入れる）
文字数の目安: 本文 300 字以内

架空の例（医師宛て）:

```
件名：【居宅療養管理指導報告】11/5訪問分（ジロー薬局）

みどり在宅クリニック　高橋 健一 先生

いつもお世話になっております。ジロー薬局の前田です。
11月5日に訪問した患者様の報告書を、添付にてお送りします。

要旨：朝の飲み忘れが週3回程度あり、残薬が4日分ありました。
次回処方で朝食後分の日数調整をご検討いただけますと幸いです。

添付：居宅療養管理指導報告書（PDF・1枚）
患者様のお名前は添付ファイルに記載しています。

ジロー薬局　薬剤師 前田 二郎　TEL ／ FAX
```

**宛先で変わる部分**: 医師は要旨を処方提案にする。ケアマネは要旨をお願いにし、「ヘルパー訪問時の声かけ」などを入れる。介護職へのメールは、事業所で受け方が決まっている場合だけにする（【提案】）。

### 4-3. チャット用

順番: 要点 1 行 → 事実 2〜3 行 → お願い 1 行 → 署名
含める欄: 服薬状況・残薬・体調の変化のうち変わった点、P のお願い。省く欄: 氏名・生年月日・住所・処方の全量・変化のない欄・定型欄
文字数の目安: 200 字以内（1 行 40 字程度）

架空の例（ケアマネ宛て。利用者ごとのグループに書く前提で、氏名なし）:

```
朝の飲み忘れが週3回。服薬カレンダーを食卓に設置しました（11/5訪問）
・残薬：朝食後分4日分。次回処方の日数調整を医師に提案します
・便通：3日に1回。センノシドを飲む目安を紙でお渡ししました
【お願い】ヘルパー訪問時の服薬の声かけをご検討ください
ジロー薬局 前田
```
（改行を除いて 131 字）

**宛先で変わる部分**

- 医師: 1 行目を処方提案にする（例:「残薬4日分。次回、朝食後分の日数調整をご検討ください」）。お願いの行は省く。
- ケアマネ: 上の例のとおり。
- 介護職: 1 行目を「お願いすること」にする（例:「朝食後の袋を、朝ごはんのあとに声かけをお願いします」）。2 行目以降に「むせ・ふらつき・便が3日出ないときはご連絡ください」。
- どの宛先でも、画面に「急ぎ・急変は電話で」と表示する。

### 4-4. 介護職向けを「その他」に当てるか、新設するか（判断材料）

| 観点 | 「その他」に当てる | 「介護職」を新設する |
|---|---|---|
| 報告書ソフトとの互換 | 宛先の選択肢（医療機関／ケアマネ／その他）は報告書ソフトと同じ並びで、変えずに済む | 選択肢が報告書ソフトと食い違う。報告書には「その他」と出すなどの対応が要る |
| 制度 | 介護職は算定要件の宛先ではない。報告書としては「その他」で足りる | 同左 |
| 中身 | 「その他」には訪問看護なども入りうる。介護職向けの平易な書き方を既定にすると合わない場合がある | 介助の範囲・観察点という介護職向けの型を、迷わず出せる |
| 実装 | 宛先の選択肢とスキーマを変えなくてよい。出力側に「介護職向け」の切り替えを足すだけ | 宛先の enum、プロンプト（P の結び）、評価の見本を足す必要がある |
| 中間案 | 宛先は「その他」のまま、④出力に「読み手: 介護職」の切り替えを置く。報告書の欄は変えない | — |

締切（11/8 20:00）を考えると、宛先の選択肢とスキーマを変えない中間案が、変更範囲が最も小さい。ただし決めるのは社長。

## 6. 調べたが見つからなかったこと

- 日本薬剤師会、都道府県薬剤師会（熊本県を含む）が公開する、医師宛て・ケアマネ宛ての訪問報告書の公式様式（静岡県薬剤師会の Word 様式と、神奈川県薬剤師会のものと見られるマニュアルは、存在は分かったが中身を読めなかった）。
- 令和6年度版の調剤報酬留意事項通知 別添3 の本文。老企第36号の令和6年度改定後の厚労省原文（Vol.1213）。
- 報告の頻度を単独で定めた通知の文言（医療・介護とも）。
- 薬剤師の項にある、ケアマネへの情報提供の方法（会議が基本、文書・メール・FAX も可）の文言。
- 医師やケアマネに「薬剤師の報告で欲しい情報」を直接聞いた調査。
- 介護職向けの服薬情報シートの公的な標準様式。飲み忘れ時の対応の公的な標準手順。
- FAX 送付状の記載事項、FAX 誤送信の防止策（2 人確認など）の国内の公的な標準。
- メール本文に氏名を書かない運用、パスワード付き PDF の是非、パスワードの別送についての医療向けの公的資料。
- チャット報告の短文の型、患者氏名の表記ルール（フルネーム／イニシャル）を定めた公的資料・職能団体資料。
- 報告書を A4 1 枚に収める決まり。
- ケアマネ宛ての敬称の公的な根拠。押印を一律に不要とする薬局・介護向けの通知。
- 個人情報の漏えい等報告の期限（通則ガイドラインを読んでいない）。
- 介護報酬の令和8年度の扱い（改定の有無を含む）。
