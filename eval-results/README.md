# eval-results（評価結果の置き場）

`npm run eval` が、架空台本（`fixtures/yamamoto-hanako/`）から下書きを作り、見本（`expected.json`）と欄ごとに比べた結果を保存する場所です。

## 使い方

```
npm run eval                                   # API を 1 回呼ぶ（費用が掛かる。1 回あたり約 $0.1 の見込み）
npm run eval -- --dry-run                      # API を呼ばず、送る内容の要約だけ表示（無料。何も保存しない）
npm run eval -- --recipient=医療機関            # 宛先の種別（ケアマネ | 医療機関 | その他。既定 ケアマネ）
npm run eval -- --fixture=fixtures/<フォルダ>   # 別の架空台本で評価
npm run eval -- --note=プロンプト修正後         # history.md のメモ欄に書く一言
```

モデルと effort は環境変数 `HOUMON_MODEL`（既定 `claude-opus-5-5`）と `HOUMON_EFFORT`（既定 `medium`）で切り替えます。
`.env` に `ANTHROPIC_API_KEY` が必要です（`.env` は Git に入れません）。

## 保存されるもの

| ファイル | 内容 | Git |
|---|---|---|
| `<日時>-<model>-<effort>.json` | 送った内容の要約・Claude の応答・比較結果 | 追跡しない（実行のたびに増えるため） |
| `history.md` | 1 回の実行につき 1 行の履歴（一致率・所要時間・トークン数） | 追跡する |
| `README.md` | このファイル | 追跡する |

## 見方

- 選択式の欄は見本と**完全一致**で判定します（正解は 100%）。台本に根拠が無い欄は「要確認」が正解です（例: センノシドの残数）。
- 備考・SOAP は文字 2 つ組（bigram）の類似度（0〜1）の目安だけを出します。最終判断は人が見比べます。
- S の引用と evidence の引用は、会話テキストに実在するか（空白・句読点を無視した部分一致）を確認します。「なし」は作り話の疑いです。
- 終了コード: 0 = 選択式 100% かつ S の引用が 1 件以上あり、すべて実在 / 2 = それ以外 / 1 = 実行エラー。
- effort を変えるとプロンプトキャッシュが切れます。比較実験は時間を空けて行ってください。
