# 個人情報・秘密情報の監査

`pii-auditor` サブエージェントが、独立したコンテキストで次の対象を調べて表で返します。

## 監査対象
- `fixtures/`（台本・見本・JSON）
- `docs/`
- `README.md`
- `src/lib/sample/`（サンプルデータ。無ければ飛ばす）
- テストファイル（`**/*.test.ts`、`**/*.test.tsx`、`**/*.spec.ts`、`tests/` や `__tests__/`）
- `public/`（画像など。画像ファイルは存在そのものを要確認として挙げる）

## 見る観点（`pii-auditor` の定義に従う）
- 架空宣言（「架空」）の有無
- 実在しそうな氏名・住所・電話・生年月日・医療機関名・事業所名
- `.env` 由来の文字列（`sk-ant-` など）
- 画像ファイル（スクリーンショットに実データが写っていないか）
- ジロー薬局・薬剤師名は社長自身の情報なので対象外

## 返す形式
表（ファイル / 行 / 内容の要約 / 判定: 架空OK・要確認・NG）と総括。**監査のみで、ファイルは編集しない**。
